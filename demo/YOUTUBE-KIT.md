**Title:**
SeatCraft — seating charts humans and AI agents solve together (WebMCP demo)

**Description:**
SeatCraft is an event seating planner built for The WebMCP Challenge. The host drags guests and locks non-negotiable seats; an AI agent solves the constraint puzzle (divorced relatives apart, couples together, grandma with family) through 15 WebMCP tools registered on navigator.modelContext — on the same live board. Every agent action is visible in an on-page activity feed, and host-locked seats are agent-proof: the human always wins.
